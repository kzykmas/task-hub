# AIW-009 AI仕事環境のグランドデザイン見直し

## なぜ今なのか（増野さんの状況認識・2026/08/11）
- **タスクボードが充実し、自分の予定とタスクはここでほぼ完結するようになった。
  自分にとってのAI秘書になってきた**
- その結果 **Googleカレンダーを見なくなってきた**。ただし
  **団体・チームで共有する予定には当然カレンダーが必要**
- 働き方が2モードに分かれている
  - **移動中**：タスクを見直す／アイデアが浮かぶ
  - **事務所**：大きなディスプレイで**全体を俯瞰しながら深掘り**する
- タスクボード・カレンダー連携・AIエージェントへの委任、**これらを全部見直す時期**

## ここから出てくる設計論点

### 1. 正本の役割分担が変わった
- **個人の予定・タスク＝タスクボード（tasks/ノート）が正本**
- **Googleカレンダー＝他者と共有する予定の置き場**に役割が縮小
- → **★規約の意味も変わる**。いまは「カレンダーから拘束を拾う」ルールだが、
  実質は「**他者と共有された拘束をボードへ取り込む**」ルールになっている。
  この観点で規約を書き直すと、@@郷野小@@のような自分用の印との線引きがはっきりする

### 2. ビューを2つに分けるべきでは
いまのボードは**1枚の静的HTML**で、移動中も事務所も同じものを見ている。
- **移動中ビュー**：至急・今日やる・期限が近いものだけ。**素早く直せる／足せる**
- **事務所ビュー**：俯瞰。2週間・タイムライン・負荷・団体別・PM研究ボード
- → 同じ正本から**2種類のビューを生成する**のが素直（生成スクリプトの分岐で済む）

### 3. 移動中の「捕捉」に摩擦がある
アイデアが浮かぶのは移動中なのに、いまは起票時に
**size／labor／parent／lead／category** まで決める前提になっている。
- → **とりあえず放り込むだけのinbox**（未分類でよい置き場）が要るのでは。
  分類はあとから事務所モードでAIと一緒に整える
- 移動中の入力は**会話（音声含む）で放り込み、AIが下書きを作る**のが現実的

### 4. AIエージェントにどこまで任せるか
現状すでにAIがやっていること／任せられそうなこと：
- 済 起票の下書き・期限のlead逆算・負荷計算・ダッシュボード生成
- 済 Googleカレンダーの走査と★予定の抽出
- 未 毎朝の自動更新（AIW-004）
- 未 未分類inboxの整理・重複検出・**ID採番の一意化**
- 未 期限の破綻検出（バッファなし区間の警告＝旧・新機能c）

### 5. 実行環境（どこで動かすか）
→ **AIW-007（データをどこに置くか）**・**AIW-008（どのランタイムで動かすか）** で扱う。
本タスクはその2つの**上位にある「そもそもどう働きたいか」**を決める枠。
