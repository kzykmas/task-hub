# AIW-012 負荷ログの構造化検討

## 概要
`docs/実績_タスク外の負荷.md` を**1ヶ月ほど日報形式で貯めたうえで**、
集計しやすい形（構造化）にするかどうかを決める。**8/18開始 → 9/18目安**。

いまは意図的に構造化していない。項目を決めて埋めさせると報告が面倒になり続かないため、
まず貯まることを優先している。

## 決めること
→ 詳細は `docs/経緯_タスク管理システム.md` の
「検討課題：タスク外の負荷の実績収集」「検討課題：ケア負荷を前提にした計画」

1. どこに貯めるか（md追記のままか、JSON/CSV等に移すか）
2. 何を記録するか（日付・区分・拘束時間・影響を受けたタスク…項目を増やしすぎない）
3. 負荷スコア（重＋軽＝7）に合流させるか
4. 週次・月次の振り返り方（AIW-005 の週1 PMレビューに載せるか）

**1ヶ月分の実データを見てから決める。** 先に仕組みを作らない。

## 経緯
- 2026/08/18 増野さん指示で起票。実績ログの新設（8/18）と同時に、
  構造化の判断を1ヶ月後に行うタスクとして切り出した。
