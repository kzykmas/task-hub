# タスク外の負荷の実績ログ（日報）

タスクとして起票していない負荷（家庭の事情・体調・急な対応・移動など）を、日付ごとに残す。

**目的は「その日タスクが進まなかった理由」を後から追えるようにすること。**
負荷スコア（重＋軽＝7が基準）はタスクだけを数えているため、
実際には終日ふさがっていた日も「7枚あったのに消化できなかった」としか見えない。その差を埋める。

## 書き方

**構造化しない。日報形式で、文章のまま残す。感想でも構わない**（2026/08/18 増野さん決定）。
項目を決めて埋めさせる形にすると報告が面倒になり、続かないため。まず貯めることを優先する。

- 日付の見出しを足して、その下に文章で書く。長さは自由
- **追記のみ。過去の日付は書き換えない**
- 1ヶ月ほど貯まったら、集計しやすい形を考える（→ AIW-012・9/18目安）

**★規約との使い分け**（2026/08/18 整理）

| | 対象 | 性質 |
|---|---|---|
| ★（`config/fixed.json` →「2週間ある」） | 事前に分かっている拘束 | **これから**の枠取り。空けておくため |
| このログ | 実際に何に時間を取られたか | **終わったこと**の記録。突発を含む |

カレンダーに入れる暇もない突発はこのログだけに書く。
事前に★を付けてあった予定は、このログでは「★の予定どおり」程度で済ませ、二重管理にしない。

## 記録

### 2026/08/18（火）

子どもの体調不良で、午前中いっぱい病院で診察。午後は自宅で看病。ほぼ終日ふさがり、
タスクはあまり進まなかった。当日のタスク実施状況は別途、増野さんの報告を受けて反映する。

増野さんより、**こうしたプライベートな事情でタスクが進まない日は多い**との補足。
子どもの体調による通院・看護に加え、2025年度まで約6年間は母の介護・入院対応があった。
今後は父の高齢化に伴う通院・看護の可能性も出てきている。
**単発の例外ではなく、継続的な前提として織り込む必要がある**
（→ `経緯_タスク管理システム.md` の「検討課題：ケア負荷を前提にした計画」）。
