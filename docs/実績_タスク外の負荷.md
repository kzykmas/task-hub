# タスク外の負荷の実績ログ

タスクとして起票していない負荷（家庭の事情・急な対応・体調・移動など）を、日付ごとに残す。

**目的は「その日タスクが進まなかった理由」を後から追えるようにすること。**
負荷スコア（重＋軽＝7が基準）はタスクだけを数えているため、
実際には終日ふさがっていた日も「7枚あったのに消化できなかった」としか見えない。
その差を埋めるための記録。

**この形式は仮置き。** 何日か貯めてから集計しやすい形を決める
（→ `経緯_タスク管理システム.md` の「検討課題：タスク外の負荷の実績収集」）。
**追記のみ。過去の行は書き換えない。**
